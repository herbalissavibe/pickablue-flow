# pickablue flow — обзор проекта

## Что это

Одностраничный маркетинговый сайт (**one-pager**) для продукта **pickablue flow** компании **pickablue GmbH** (Wiesbaden). Страница объясняет, как существующие материалы (сайт, PDF, базы, внешние источники) превращаются в интерактивные форматы (аудиогиды, квизы, Hörspiele и т.д.) в экосистеме pickablue — с курированием, контролем качества и доступом гостей через **QR в мобильном браузере** без отдельного приложения.

## Цели страницы

1. **Позиционирование:** «kuratiert statt generiert» — не сырой AI-контент, а контролируемый пайплайн.
2. **Понятный сценарий:** визуально показать шаги **select → transform → review → publish** и примеры кейсов.
3. **Доверие:** три опоры (качество/контроль, прозрачные затраты, интеграция с текущими системами).
4. **Конверсия:** блок «Kontaktieren Sie uns» и юридические ссылки в футере.

## Целевая аудитория

- Организации в **туризме**, **муниципалитетах/регионах**, **культурных учреждениях**.
- Маркетинг и IT-лидеры, которым важны: снижение ручного продакшена контента, мультиязычность, согласованность с уже существующими каналами.

## Язык и контент

- Основной язык интерфейса и копирайта: **немецкий (DE)**.
- Тексты секций — по брифу (RTF/PDF); блок с тремя кейсами дополняет RTF; третий кейс (**Datacycle**) в макете может содержать placeholder до финального текста.

## Ключевые UX-требования

| Требование | Описание |
|------------|----------|
| Hero video | Фоновое **видео на всю ширину вьюпорта** (object-fit: cover), с fallback poster и учётом `prefers-reduced-motion`. |
| Волна / разделитель | Плавный переход между hero и белым контентом (SVG или mask). |
| Логотип «FLOW» | Крупная типографика с перекрывающимися цветами букв (blend modes). |
| Кейсы | Три карточки на синем фоне; по клику — **полноэкранное модальное видео** (Screenvideo + Fullscreen-Modal). |
| Доступность | Фокус, клавиатура, aria для модалок и видео, контраст текста на градиентах. |
| Производительность | Сжатые видео (несколько источников / адаптивный битрейт), lazy для нижних секций где уместно. |

## Референсы дизайна

Визуальный язык: вода, пузыри, градиенты синего; акцентные цвета букв FLOW и pill-кнопок процесса. Детали палитры и секций — в `ARCHITECTURE.md` и `TECH_STACK.md`.

## Связанные документы

- `ARCHITECTURE.md` — структура репозитория, компоненты, токены.
- `TECH_STACK.md` — стек и обоснование.
- `CURRENT_STATUS.md` — прогресс и ближайшие задачи.
